Welcome to the Windows 9x QuickInstall reference image!
A one-stop solution for classic and modern machines alike.

Featuring SweetLow's AHCI, USB 2.0, USB Mass Storage, NTFS and NVMe drivers,
official updates, unofficial patches, Quality-of-Life fixes,
and a huge driver library for old and modern(-ish) hardware!

Freezing or disk issues? Try disabling DMA (keys 0-7) at the boot prompt.
Modern machine? Press 'A' at the boot prompt to enable ACPI/APIC support!

Did you know? QuickInstall now includes 'witchery', Fagear's 3dfx Voodoo 2 
diagnostics tool! Try it in the included Linux shell!
